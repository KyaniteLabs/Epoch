# Community Data

This directory contains community-contributed datasets that improve Epoch's estimation accuracy.

## Guidelines

- Each file should follow the naming convention `<contributor-id>-<type>.json` and the format described in [CONTRIBUTING-data.md](../../CONTRIBUTING-data.md).
- Do not modify other contributors' files without their consent.
- All files are validated by CI on every PR against the schemas in `data/schemas/`.
- Any file containing personally identifiable information will be rejected.
