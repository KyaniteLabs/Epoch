The Problem

Large language models have no persistent hidden state. Positional encodings represent token sequence position, not real-world time. Self-attention provably cannot model counting behaviors. This creates systematic failures in duration prediction, temporal ordering, and time estimation.

01

Temporal Blindness

LLMs treat tokens as discrete temporal units. Events 10 tokens apart have identical encodings whether separated by 1 second or 1 hour.

02

Duration Prediction Failure

Coding agents estimate in token budgets, not minutes. A 200K-token session can take 5 minutes or 5 hours — agents can't tell the difference.

03

Planning Fallacy Amplified

GPT-5.2 predicts 73% task success at a 35% true rate. LLMs replicate and amplify human optimism bias through agentic overconfidence.

Research finding: A UPenn negotiation study showed 4% deal closure under wall-clock time limits vs 99% under turn-based limits. Injecting explicit time state into prompts produced an 8x improvement in negotiation outcomes. Epoch makes time legible to LLMs through structured external tools — not prompt hacks.

5-Layer Architecture

Make time legible to LLMs, not make LLMs better at time. Each layer provides structured external representations that LLMs can request rather than calculate.

L5

Advanced Analytics

Monte Carlo simulation, token-to-time bridge, planning fallacy correction, team velocity calibration

L4

Data Integration

Reference class forecasting, estimation accuracy tracking, historical data calibration

Time retrieval, timezone conversion, duration parsing, date arithmetic

Example: Token-to-Time Bridge

A coding agent plans to use 50,000 tokens with 10 tool calls on Claude Sonnet. How long will it actually take?

Input
token_time_bridge({
  tokens: 50000,
  model: "claude-sonnet-4-20250514",
  tool_calls: 10,
  reasoning_depth: "deep"
})
Output
{
  estimatedSeconds: 835,
  estimatedMinutes: 13.9,
  confidence: "likely",
  category: "medium",
  model: "claude-sonnet-4-20250514"
}

Installation

Claude Code

$ claude mcp add epoch -- npx @kyanitelabs/epoch

}
