FAQ

Common questions

Does it work with Cursor, Codex CLI, Cline, and other tools?
Yes. Epoch works with any MCP-compatible client including Claude Code, Cursor, Codex CLI, Cline, Zed, Windsurf, VS Code, and any tool supporting the Model Context Protocol. The same 24 tools are available everywhere.
Is it really free?
Yes. Epoch is MIT-licensed open source. Free forever. No usage limits, no API keys required, no lock-in. The code is public — you can audit it, fork it, or self-host.
Does it slow down my AI?
No. Epoch runs as an external MCP tool. Tool calls add milliseconds, not seconds. Your AI calls the tools only when it needs an estimate — the rest of the time, it runs exactly as before.
What if my team is remote across timezones?
Epoch has full timezone support with IANA timezone conversion, holiday-aware business day calculations for 5 countries (US, UK, FR, DE, JP), and date arithmetic built in. Ask "how many business days between New York and Tokyo deadlines?" and get an accurate answer.
What estimation methods does Epoch use?
PERT three-point estimation, COCOMO II (with LLM-adapted cost drivers), Monte Carlo simulation, reference class forecasting, critical path method, and sprint velocity forecasting. Each method has been calibrated against historical project data.
How does self-improvement work?
Every estimate generates a feedback token. Record the actual hours when the work is done, and Epoch auto-calibrates correction factors for that task type and complexity. After 5+ matched pairs per task type, self-improvement kicks in automatically. More data = better estimates.
